01

Introduction & Accès à Billetweb

Billetweb est la plateforme de billetterie en ligne que L'Oasis Familiale utilise pour gérer les inscriptions aux stages pour enfants (Centre de Vacances, ateliers, etc.). Ce guide vous accompagne pas à pas dans la création d'un événement.

Accès rapide

  • URL du back-office : https://www.billetweb.fr/bo/
  • Connexion : Utilisez vos identifiants Oasis
  • Coût : ≈ 0,29 € + 1 % par billet vendu (pas d'abonnement)
  • Support : support@billetweb.fr

Se connecter au back-office

  1. Ouvrez votre navigateur et rendez-vous sur billetweb.fr
  2. Cliquez sur "Connexion" en haut à droite
  3. Entrez votre adresse e-mail et votre mot de passe
  4. Vous arrivez sur le tableau de bord qui liste tous vos événements

Créer un nouvel événement (stage)

Chaque stage pour enfants correspond à un événement sur Billetweb. Voici comment en créer un nouveau.

Étape 1 — Lancer la création

Depuis le tableau de bord :

  1. Cliquez sur le bouton "+ Créer un événement" (généralement en haut à droite ou au centre de la page)
  2. Un assistant de création s'ouvre
Tableau de bord › + Créer un événement
📸 Capture d'écran : Bouton "Créer un événement" sur le tableau de bord Insérer ici une capture du tableau de bord avec le bouton mis en évidence

Étape 2 — Choisir le type d'événement

Billetweb peut proposer différents types (concert, conférence, activité…). Pour un stage enfants :

  • Choisissez le type le plus adapté : "Activité", "Stage" ou "Atelier" selon les options disponibles
  • Si aucun type ne correspond exactement, choisissez "Autre"

04

Créer les tarifs et catégories de billets

C'est ici que vous définissez les différentes formules d'inscription au stage. Vous pouvez créer autant de tarifs que nécessaire.

Événement › Billetterie › Tarifs

Ajouter un tarif

  1. Dans la page de votre événement, allez dans l'onglet "Billetterie" ou "Tarifs"
  2. Cliquez sur "Ajouter un tarif"
  3. Remplissez les champs suivants :
Champ Description
Nom du tarif Ex : "Stage Semaine complète", "Stage 1 journée", "Garderie matin"
Prix Le montant TTC. Mettez 0 € si le stage est gratuit.
Quantité disponible Le nombre maximum de places (ex : 20 enfants par semaine)
Description Détails du tarif (ce qui est inclus, âge concerné…)
Dates de vente Période pendant laquelle ce tarif est disponible à la vente (optionnel)
Nombre min/max par commande Limitez si besoin (ex : max 5 billets par commande pour éviter les abus)

Exemple de tarifs pour un stage enfants

Tarif Prix Places Détail
Semaine complète (3-6 ans) 75 € 15 Du lundi au vendredi, 8h30-16h30
Semaine complète (6-12 ans) 85 € 20 Du lundi au vendredi, 8h30-16h30

💡
Gestion des quotas Billetweb gère automatiquement les places restantes. Quand un tarif est complet, il s'affiche comme "Complet" et les parents ne peuvent plus le sélectionner. Vous pouvez toujours augmenter le quota manuellement si une place se libère.
⚠️
Commission Billetweb Si le billet est payant, Billetweb prélève une commission d'environ 0,29 € + 1 % par billet. Vous pouvez choisir de l'absorber (incluse dans votre prix) ou de la répercuter sur le parent (ajoutée au prix affiché). Configurez cela dans les options de paiement.
05

Personnaliser le formulaire d'inscription

Le formulaire permet de collecter les informations nécessaires sur l'enfant et le parent. C'est essentiel pour les stages enfants.

Événement › Billetterie › Formulaire

Ajouter des champs personnalisés

Par défaut, Billetweb demande le nom et l'e-mail de l'acheteur. Pour un stage enfants, vous devez ajouter des champs supplémentaires :

  1. Allez dans la section "Formulaire" de votre événement
  2. Cliquez sur "Ajouter un champ"
  3. Choisissez le type de champ (texte, liste déroulante, case à cocher…)
  4. Renseignez le libellé et indiquez si le champ est obligatoire

🔥
Astuce — Champs par billet Si un parent inscrit plusieurs enfants, configurez les champs pour qu'ils soient demandés par billet (et non par commande). Ainsi, chaque enfant aura sa propre fiche. Vérifiez l'option "Demander pour chaque billet" ou "Par participant" selon la formulation Billetweb.

Personnaliser l'apparence de la page

Donnez une identité visuelle à votre page de billetterie pour rassurer les parents et renforcer l'image de L'Oasis Familiale.

Événement › Personnalisation

Éléments visuels à configurer

  • Image de couverture / bannière : photo principale affichée en haut de la page. Utilisez une photo d'enfants en activité ou l'affiche du stage (idéalement 1200 × 630 px).
  • Logo : ajoutez le logo de L'Oasis Familiale pour crédibiliser la page.
  • Couleurs : personnalisez les couleurs du thème pour correspondre à la charte graphique de L'Oasis (vert, couleurs naturelles…).
  • Description riche : vous pouvez mettre en forme le texte (gras, listes, liens) et ajouter des images dans la description.

📸 Capture d'écran : Configuration des moyens de paiement Insérer ici une capture de la configuration des paiements

Gestion des frais de commission

Vous avez deux options pour les frais Billetweb :

  • Absorber les frais : Vous recevez le prix du billet moins la commission. Le parent paie le prix affiché. Recommandé pour L'Oasis
  • Répercuter les frais : La commission est ajoutée au prix du billet. Le parent paie un peu plus que le prix affiché.
✅
Bonne nouvelle Si le stage est gratuit (prix à 0 €), Billetweb ne prélève aucune commission. La plateforme est entièrement gratuite pour les événements gratuits.
08

Publier et partager le stage

Une fois tout configuré, il est temps de rendre la billetterie accessible aux parents.

Publication de l'événement

  1. Vérifiez toutes les informations via le bouton "Prévisualiser"
  2. Si tout est correct, cliquez sur "Publier" ou activez la vente en ligne
  3. Billetweb génère automatiquement une URL publique pour votre événement
📸 Capture d'écran : Bouton de publication et URL générée Insérer ici une capture montrant la publication et le lien

Partager la billetterie

Plusieurs canaux pour diffuser l'inscription :

1

Lien direct

Copiez l'URL de l'événement et partagez-la par e-mail, SMS, ou messagerie (WhatsApp, Messenger…). C'est le moyen le plus simple.

2

Réseaux sociaux

Partagez le lien sur la page Facebook de L'Oasis Familiale et sur Instagram. Billetweb propose des boutons de partage intégrés.

3

Intégration sur le site web

Billetweb fournit un code d'intégration (widget) que vous pouvez ajouter directement sur le site web de L'Oasis Familiale pour que les parents s'inscrivent sans quitter le site.

4

QR Code / Affiche

Générez un QR code pointant vers la page d'inscription et intégrez-le sur les affiches physiques et flyers distribués à Hannut et Waremme.

Gérer les inscriptions au quotidien

Une fois la billetterie en ligne, voici comment suivre et gérer les inscriptions des enfants.

Tableau de bord › Votre événement › Participants

Tableau de bord de l'événement

En cliquant sur votre événement depuis le tableau de bord, vous accédez à :

  • Statistiques en temps réel : nombre d'inscriptions, revenus, taux de remplissage
  • Liste des participants : nom, e-mail, tarif choisi, statut du paiement
  • Détails de chaque inscription : toutes les informations du formulaire (enfant, parent, allergies, etc.)

Exporter la liste des inscrits

Pour préparer le stage, vous aurez besoin de la liste complète :

  1. Allez dans "Participants" ou "Liste des inscrits"
  2. Cliquez sur "Exporter"
  3. Choisissez le format Excel (.xlsx) ou CSV
  4. Le fichier contient tous les champs du formulaire : parfait pour faire les listes de groupes, préparer les badges nominatifs ou lister les allergies

10

Le jour J — Contrôle des entrées

Le premier jour du stage, vous pouvez vérifier les inscriptions de plusieurs manières.

Option 1 — Liste imprimée (le plus simple)

  1. Exportez la liste des inscrits la veille (voir section précédente)
  2. Imprimez-la
  3. Cochez les enfants à leur arrivée

C'est la méthode la plus adaptée pour un stage enfants de taille modeste.

Option 2 — Contrôle sur ordinateur

  1. Connectez-vous à Billetweb depuis un ordinateur ou une tablette
  2. Ouvrez la page de contrôle de l'événement
  3. Cochez les enfants au fur et à mesure de leur arrivée

Option 3 — Application mobile (scan QR code)

  1. Téléchargez l'application Billetweb sur votre smartphone (iOS / Android)
  2. Connectez-vous avec vos identifiants
  3. Scannez le QR code du billet que le parent présente sur son téléphone ou en version imprimée
  4. L'application confirme la validité et marque l'entrée

11

Dupliquer un stage pour la prochaine session

Lorsque vous organisez un nouveau stage similaire (ex : Semaine 2 d'été), inutile de tout recréer. Dupliquez l'événement existant !

Comment dupliquer un événement

  1. Depuis le tableau de bord, repérez le stage que vous souhaitez dupliquer
  2. Cliquez sur les 3 petits points (menu d'options) ou sur l'icône de duplication à côté de l'événement
  3. Sélectionnez "Dupliquer"
  4. Un nouvel événement est créé avec toutes les mêmes informations (description, tarifs, formulaire, design)
  5. Modifiez uniquement ce qui change :
    • Titre (ex : "Semaine 2" au lieu de "Semaine 1")
    • Dates
    • Quotas (les compteurs sont remis à zéro)
    • Visuel si nécessaire
  6. Publiez le nouvel événement
📸 Capture d'écran : Option de duplication d'un événement Insérer ici une capture montrant l'option de duplication
🔥
Workflow recommandé pour les vacances d'été Créez le premier stage en détail, puis dupliquez-le pour chaque semaine suivante. Cela vous assure une cohérence entre les stages et vous fait gagner un temps considérable.

Checklist avant publication

Avant de mettre votre billetterie en ligne, vérifiez tous les points suivants :

Informations générales

  • Le titre est clair et contient la période (ex : "Stage Été — Semaine 1")
  • Les dates et horaires sont corrects
  • L'adresse est complète et exacte (Rue de Wavre 22B, 4280 Hannut)
  • La description mentionne : les activités, la tranche d'âge, les infos pratiques (repas, matériel…)
  • Un visuel attractif est ajouté

Tarifs et places

  • Tous les tarifs sont créés avec les bons prix
  • Le nombre de places est correct pour chaque tarif
  • Les dates de vente sont configurées (si nécessaire)
  • La commission Billetweb est gérée (absorbée ou répercutée)

Formulaire d'inscription

  • Les champs enfant sont présents (prénom, nom, date de naissance)
  • Le téléphone du parent est demandé
  • Les allergies / santé sont demandés
  • Le contact d'urgence est demandé
  • Les champs sont bien configurés par billet/participant

Vérification finale

  • La prévisualisation est vérifiée (version desktop ET mobile)
  • Un test d'inscription a été réalisé (inscrivez-vous vous-même pour tester le parcours)
  • L'e-mail de confirmation est bien reçu après le test
  • Le paiement fonctionne correctement
⚠️
N'oubliez pas de supprimer votre inscription test ! Après avoir vérifié que tout fonctionne, pensez à annuler/supprimer la commande test pour ne pas fausser vos statistiques et libérer la place.

Questions fréquentes

Un parent veut s'inscrire mais n'a pas accès à internet ?

Vous pouvez l'inscrire manuellement depuis le back-office : Participants → Ajouter une commande. Vous remplirez le formulaire à sa place et pourrez encaisser le paiement en espèces ou par virement.

Un parent souhaite annuler, comment le rembourser ?

Allez dans la liste des participants, cliquez sur sa commande, puis sur "Rembourser". Le remboursement est traité automatiquement si le paiement avait été fait par carte. Pour les paiements en espèces, procédez au remboursement manuellement et marquez la commande comme annulée.

Comment modifier un événement déjà publié ?

Vous pouvez modifier à tout moment les informations, les tarifs, les quotas et le formulaire d'un événement publié. Les changements sont appliqués immédiatement. Attention : si des inscriptions sont déjà enregistrées, ne modifiez pas les tarifs existants (créez-en de nouveaux si besoin).

Comment recevoir les paiements ?

Billetweb verse les montants collectés sur votre compte bancaire, généralement sous 15 jours après la transaction. Assurez-vous que vos coordonnées bancaires sont correctement renseignées dans les paramètres de votre compte organisateur.

Où trouver de l'aide ?

Le support Billetweb est joignable par e-mail à support@billetweb.fr. Leur documentation en ligne est également très complète : billetweb.fr/fr-fr/questions-frequentes/
